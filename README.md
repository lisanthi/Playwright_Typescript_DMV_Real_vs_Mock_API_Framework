Prerequisites
1.	Git: Ensure Git is installed to clone the repository.	
2.	Docker Desktop: Install and start Docker Desktop (which includes Docker Compose).

Run the below commands in command prompt
1.git clone https://github.com/AviPeltz/OS-DMV-Waiting-Queue.git 
2.cd OS-DMV-Waiting-Queue
3.docker compose up --build
4.Make sure local DMV OpenQueue application opens without any issues.
http://localhost:3000/
